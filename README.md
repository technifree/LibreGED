## What is LibreGED?

LibreGED is a free, open-source document management system for desktop. It lets you organise your files into folders, index and search their content, preview them without opening another app, and print directly from the interface. PDF, images, Office documents, emails (EML, MHTML) — everything in one place.

No cloud, no account, no telemetry. Your files stay on your machine.

## Features

- Folder tree with drag & drop reorganisation
- Full-text search with instant indexing
- Built-in previewer (PDF, images, Office/ODF, EML, MHTML)
- Batch import and optional scanner acquisition
- Print from the preview pane
- Light and dark theme
- 13 interface languages (EN, FR, DE, ES, IT, PT, NL, PL, RU, ZH, JA, AR, TR)
- Fully portable — no installer, runs from any directory

## Download

Pre-built binaries are available on the [releases page](https://github.com/technifree/LibreGED/releases/latest) — no Python required.

| File | Platform |
|---|---|
| `LibreGED-linux.tar.gz` | Linux x86-64 |
| `LibreGED-windows.zip` | Windows x64 |
| `LibreGED-macos.zip` | macOS Universal |

**Linux / macOS**
```bash
tar -xzf LibreGED-linux.tar.gz
cd LibreGED && ./LibreGED
```

**Windows** — extract the zip, run `LibreGED.exe`.

## Build from source

```bash
git clone https://github.com/technifree/LibreGED.git
cd LibreGED
pip install -r requirements.txt
python main.py
```

Requires Python 3.10+ and PySide6 6.9.

## Qu'est-ce que LibreGED ?

LibreGED est un gestionnaire électronique de documents (GED) libre et multiplateforme. Il permet d'organiser ses fichiers en dossiers, d'indexer et rechercher leur contenu, de les prévisualiser sans ouvrir une autre application, et d'imprimer directement depuis l'interface. PDF, images, documents Office, emails (EML, MHTML) — tout au même endroit.

Pas de cloud, pas de compte, pas de télémétrie. Les fichiers restent sur votre machine.

## Fonctionnalités

- Arborescence de dossiers avec réorganisation par glisser-déposer
- Recherche plein texte avec indexation instantanée
- Prévisualisation intégrée (PDF, images, Office/ODF, EML, MHTML)
- Import en masse et acquisition scanner optionnelle
- Impression depuis le panneau de prévisualisation
- Thème clair et sombre
- 13 langues d'interface (FR, EN, DE, ES, IT, PT, NL, PL, RU, ZH, JA, AR, TR)
- Entièrement portable — sans installeur, fonctionne depuis n'importe quel répertoire
