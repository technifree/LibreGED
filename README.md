## Overview

**LibreGED** is a free, open-source and cross-platform document management system (DMS) designed for individuals and small teams. It lets you organize, index, preview, search and print your documents — PDFs, images, Office files, emails and more — from a clean, native desktop interface.

No cloud, no subscription, no tracking. Your files stay on your machine.

### ✨ Key features

- 📁 **Folder-based organization** — drag & drop, tree view, icon browser
- 🔍 **Full-text search** — instant indexing across all your documents
- 👁️ **Built-in previewer** — PDF, images, Office/ODF, email (EML, MHTML)
- 🖨️ **Print support** — directly from the preview pane
- 📥 **Import & scan** — bulk import with optional scanner acquisition
- 🌍 **13 languages** — EN, FR, DE, ES, IT, PT, NL, PL, RU, ZH, JA, AR, TR
- 🎨 **Light / Dark theme** — follows your system or your preference
- 💾 **Fully portable** — no installer needed, runs from any folder

### 🖥️ Supported platforms

| Platform | Status | Notes |
|----------|--------|-------|
| 🐧 Linux | ✅ Stable | Ubuntu 22.04+ / Debian / Fedora |
| 🪟 Windows | ✅ Stable | Windows 10 / 11 (x64) |
| 🍎 macOS | ✅ Stable | macOS 12 Monterey and later (Apple Silicon & Intel) |

### 📦 Download

Pre-built binaries (no Python required) are available on the
[Releases page](https://github.com/technifree/LibreGED/releases/latest):

| File | Platform |
|------|----------|
| `LibreGED-linux.tar.gz` | Linux x86-64 |
| `LibreGED-windows.zip` | Windows x64 |
| `LibreGED-macos.zip` | macOS (Universal) |

### 🚀 Quick start

**Linux / macOS**
```bash
# Extract the archive
tar -xzf LibreGED-linux.tar.gz   # or unzip LibreGED-macos.zip
cd LibreGED
./LibreGED
```

**Windows** — extract the `.zip`, then double-click `LibreGED.exe`.

### 🔧 Build from source

```bash
git clone https://github.com/technifree/LibreGED.git
cd LibreGED
pip install -r requirements.txt
python main.py
```

> Requires Python 3.10+ and PySide6 6.9+.

## Présentation

**LibreGED** est un gestionnaire électronique de documents (GED) libre, open-source et multiplateforme, conçu pour les particuliers et les petites équipes. Il permet d'organiser, d'indexer, de prévisualiser, de rechercher et d'imprimer vos documents — PDF, images, fichiers Office, emails et bien plus — depuis une interface bureau native et épurée.

Pas de cloud, pas d'abonnement, pas de pistage. Vos fichiers restent sur votre machine.

### ✨ Fonctionnalités principales

- 📁 **Organisation par dossiers** — glisser-déposer, arborescence, vue en icônes
- 🔍 **Recherche plein texte** — indexation instantanée de tous vos documents
- 👁️ **Prévisualisation intégrée** — PDF, images, Office/ODF, emails (EML, MHTML)
- 🖨️ **Impression** — directement depuis le panneau de prévisualisation
- 📥 **Import & numérisation** — import en masse avec acquisition scanner optionnelle
- 🌍 **13 langues** — FR, EN, DE, ES, IT, PT, NL, PL, RU, ZH, JA, AR, TR
- 🎨 **Thème clair / sombre** — suit votre système ou votre préférence
- 💾 **Entièrement portable** — sans installeur, fonctionne depuis n'importe quel dossier
